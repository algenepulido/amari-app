## What AMARI is

AMARI is an invitation-only membership app for an African diaspora professional community. Members
receive a news and intelligence briefing, hand-written Pulse editions, events with QR tickets,
member matching and a project map ("Aligned"), consented introductions to project owners, and a
profile with a membership card. Five tiers exist: member, silver, gold, platinum, laureate.
Administrators run invitations, events, check-in, moderation and Pulse authoring from inside the app.

## Stack

Expo SDK `~54.0.33`, React Native `0.81.5`, React `19.1.0`, TypeScript `~5.9`, expo-router `~6.0.23`
with typed routes, TanStack Query 5, zustand 5, zod 4, Supabase JS 2, Mapbox (`@rnmapbox/maps` 10),
expo-notifications with the Expo push service, expo-secure-store for the session. Server side is
Supabase only: PostgreSQL with RLS, 65 application SECURITY DEFINER functions, six Deno Edge
Functions, pg_cron, pg_net, Vault and PostGIS. There is no separate application server.

## Five things to know before you touch anything

- **There is no staging environment.** Any negative test against a deployed database is a test against production. Decide the environment question with Jeremy before running anything that writes. See `04` and `21`.
- **The 22 September containment closed the stranger-to-admin chain, but the short six-character codes it introduced are only as safe as the throttles around them, and `redeem_invitation_code` has no throttle.** See HO-04 in `06`.
- **The Aligned gold-tier gate is enforced on the map functions but not on the tables behind them.** `map_cache_*` and approved `projects` rows are readable by any signed-in account, and sign-up is open. See HO-01 and HO-02.
- **Media V1 is a build, not a finish.** The schema has `media_type`, `duration_seconds` and `format_meta` on `news_articles`, a feed badge renders, and `expo-av` is installed but unused. There is no upload path, no player, no media bucket and no access model.
- **The test suite proves logic, not behaviour.** 77 Jest tests in 10 suites, all pure helpers, plus 15 Deno tests and 5 pgTAP files in CI. Nothing renders a component, and 1.2.5 was not acceptance-tested on hardware.
